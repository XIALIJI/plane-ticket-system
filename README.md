# 航空票务管理系统（Socket网络版）

## 项目简介

本项目基于 C 语言开发，实现了一个采用 Client/Server（C/S）架构的航空票务管理系统。

系统使用 TCP Socket 实现客户端与服务器之间的通信，支持用户注册、登录、航班查询、订票、退票、订单管理、候补队列管理以及管理员后台管理等功能。

## 系统架构

```text
客户端(Client)
        │
        │ TCP Socket
        ▼
服务器(Server)
        │
        ▼
数据文件(users.txt、flights.txt、orders.txt)
```

## 运行方法

### 启动服务器

运行：

plane_server

服务器监听：

127.0.0.1:8888

### 启动客户端

运行：

plane_client

### 测试账号
